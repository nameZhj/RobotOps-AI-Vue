# Manual Smoke Checklist

> 本项目不保留单元测试文件或测试框架。发布前按此清单进行人工检查，并记录浏览器、屏幕尺寸和结果。

## 1. 普通业务页面

- [ ] 检查 1920×1080、1366×768、1024×768、768×1024、390×844 和 320×640。
- [ ] 检查浏览器缩放 200%，以及设备像素比 1 / 2。
- [ ] 页面本身没有横向溢出；表格和导航只在各自容器内滚动。
- [ ] 长设备 ID、任务名称、路径和时间戳不会撑开卡片或挤压按钮。
- [ ] 页面窗口变化后，卡片、表单、表格和导航保持可读。
- [ ] 按钮文字居中；默认、悬停、按下、焦点、加载和禁用状态均可辨认。

## 2. 可视化大屏（单独验收，不适用普通页面规则）

大屏设计尺寸固定为 1920×1080（16:9），所有组件必须作为一个整体等比例缩放。

- [ ] 1920×1080、2560×1440、3840×2160：画布完整显示，内部组件比例不变。
- [ ] 1366×768、1440×900（16:10）、1024×768（4:3）、3440×1440（21:9）：画布居中，必要时四周留白，不拉伸、不裁切。
- [ ] 390×844、768×1024 等竖屏：仍保持 16:9 整体缩放，不得切换成单列或重新排列面板。
- [ ] 任意分辨率下 document、html、body、#app、大屏视口、设计画布和内部面板都没有水平或垂直滚动条。
- [ ] 检查浏览器窗口连续拖动、全屏进入/退出、显示器切换后，画布会重新计算比例并保持居中。
- [ ] 检查缩放后文字、圆形、图标、地图和图表没有被单独拉伸或变形。
- [ ] 内容不会超出 1920×1080 设计画布；信息过多时应减少条目、精简文案或轮播，不得增加滚动条。
- [ ] 从大屏返回普通页面后，页面滚动能力恢复，html/body 不残留 visualization-mode class。

## 3. 颜色、控件与可读性

- [ ] 普通文字与背景对比度至少 4.5:1；大字号至少 3:1。
- [ ] 主按钮、次按钮、文字按钮及禁用态文字清晰可见。
- [ ] 选中导航、下拉选项、表格行、复选框、单选框和 Tab 状态清晰可辨。
- [ ] 状态不能只通过颜色表达；必须同时出现文字或图标。
- [ ] 键盘操作时焦点清晰可见；系统 reduced-motion 设置不会破坏交互。

## 4. 登录与 HTTP

- [ ] Mock 登录只用于本地开发；生产构建拒绝 Mock 模式。
- [ ] access token 只在内存中；refresh token 由 HttpOnly Cookie 管理。
- [ ] 同时返回的多个 401 只触发一次 Token 刷新。
- [ ] GET 可在刷新后重试；非幂等写请求只有带 Idempotency-Key 才能重试。
- [ ] 超时、取消、网络错误、JSON 错误和 204 响应均有明确处理。
- [ ] 浏览器存储和日志中没有密码、Token、SSH 密钥或 MQTT 凭证。

## 5. 地图与三维视图

- [ ] PGM 未匹配 YAML 时不显示带有猜测原点或分辨率的地图。
- [ ] 选择新 PGM 会清除旧 YAML；YAML 中 image 文件名不匹配时阻止加载。
- [ ] PGM P2/P5、非法尺寸或非法元数据会给出明确错误。
- [ ] PCD 文件大小限制和 WebGL 不可用提示正常。
- [ ] 离开地图页面时 Three.js geometry、material、texture、renderer 和 ResizeObserver 均正确释放。

## 6. MQTT 网关

- [ ] ticket 接口要求用户登录，并返回短时有效的 WSS ticket。
- [ ] Broker 通过服务端 Topic ACL 限制用户可访问的站点、设备和 Topic。
- [ ] 前端环境变量、浏览器存储、URL 和日志中没有长期 Broker 凭证。
- [ ] 连接成功后订阅和消息分发正常。
- [ ] 网络断开后按退避策略重连，并获取新 ticket、恢复订阅。
- [ ] ticket 失效或 ACL 拒绝后停止自动重试，等待重新登录或人工处理。
- [ ] 取消订阅和 disconnect 会清理订阅及定时器。
- [ ] QoS 1 消费方能处理重复消息；控制命令仍通过后端 API 提交。

## 7. 构建检查

```bash
npm run typecheck
npm run build
```

记录浏览器、屏幕尺寸、结果和问题。不要为满足检查要求而新增测试目录。
